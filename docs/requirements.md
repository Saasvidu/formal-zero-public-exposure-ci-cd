# Requirements

These are the obligations. The words system, configuration, asset, internet, and reach are defined in [Principles](principles.md).

## The app

There is one single-page web app. Public users can retrieve it.

The asset those users reach is not an asset the configuration holds. The mechanism that serves the app is outside the configuration.

## The pipeline

The system is the CI/CD pipeline. It admits one configuration.

The internet reaches no asset in the configuration the system admits.

That obligation uses the open interaction. The configuration holds the asset, and it admits an interaction whose initiating party is the internet. A refusal leaves the obligation failed. Acceptance is not a way to meet it.

An asset the configuration does not hold is outside the pipeline obligation.
